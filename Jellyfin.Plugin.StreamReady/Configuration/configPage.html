menu_bookHow StreamReady works

Jellyfin live-transcodes when a client cannot Direct Play the container, video codec, HDR range, or audio codec. StreamReady does that work ahead of time and writes a stream-friendly file.

Manual: Scan → review Needs Encoding → Encode one or selected files.

Auto Direct Pre-Transcode: Scan results go straight into the queue. Still one encode at a time, still skips files that are playing.

Smart planning remuxes when only the container is wrong, copies video when only audio is wrong, and fully encodes for HEVC 10-bit, Dolby Vision, or oversized files.

Install via a custom catalog: Dashboard → Plugins → Repositories, then add this plugin’s manifest.json URL from the GitHub repository.
